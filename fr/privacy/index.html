Politique de confidentialité

Dernière mise à jour : juin 2025

1. Informations que nous recueillons

DELE B2 Prep recueille le minimum d'informations nécessaires au fonctionnement de l'application :

  • Données d'utilisation : Progrès dans les examens, scores et préférences de l'application. Ces données sont stockées localement sur votre appareil.
  • Analyse : Nous utilisons Google Analytics pour comprendre comment l'application est utilisée de manière agrégée et anonyme (pages visitées, durée de session).
  • Abonnements : Les paiements sont entièrement traités par Apple via l'App Store. Nous n'avons pas accès à vos informations de paiement.

2. Comment nous utilisons les informations

Nous utilisons les données recueillies exclusivement pour :

  • Enregistrer vos progrès et préférences
  • Améliorer l'application et corriger les erreurs
  • Comprendre les modèles d'utilisation généraux

3. Partage de données

Nous ne vendons, louons ni partageons vos données personnelles avec des tiers. Les seuls services tiers que nous utilisons sont :

  • Google Analytics (analyse web anonyme)
  • Apple App Store (traitement des paiements)

4. Stockage des données

Vos progrès et données de l'application sont stockés localement sur votre appareil. Nous ne maintenons pas de serveurs avec des données personnelles d'utilisateurs.

5. Vos droits

Vous pouvez :

  • Supprimer toutes vos données en supprimant l'application de votre appareil
  • Demander la suppression de votre compte depuis l'application (Profil > Supprimer le compte)
  • Nous contacter pour toute question concernant vos données

6. Mineurs

L'application n'est pas destinée aux mineurs de moins de 13 ans. Nous ne recueillons pas consciemment d'informations sur les mineurs de moins de 13 ans.

7. Changements dans cette politique

Nous pouvons mettre à jour cette politique occasionnellement. Nous publierons tout changement sur cette page avec la date de mise à jour.

8. Contact

Si vous avez des questions concernant cette politique de confidentialité, contactez-nous à hello@prepdele.com.
